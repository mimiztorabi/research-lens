# Contributor guide

<!-- This file explains how to work in this portfolio repository. -->

## Purpose
This repository is a **public portfolio case study for a Senior Product Manager**. It demonstrates product thinking around an AI-assisted research workflow; it is not a production application.

## Working rules
- Keep language clear enough for a reviewer unfamiliar with the project.
- Keep the prototype static: no API keys, backends, databases, analytics, paid services, or external dependencies.
- Treat all prototype content as fictional. Do not put real customer, confidential, or personal data into examples.
- When changing product decisions, update the relevant document in `docs/` and preserve the stated assumptions.
- Use comments at the top of new source and documentation files to explain their purpose.

## Validation
Open `prototype/index.html` in a browser, or serve the repository with `python3 -m http.server`, to review the static prototype.
